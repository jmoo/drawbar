## The activity log

Click the status line at the bottom of the window or choose **View ▸ Activity
log**. Choose **Problems** to see just the entries that need attention. The
log often names the file, the slot or the next action. **Help ▸ Copy activity
log** copies the whole log, including filenames.

## Report a problem

1. Choose **Help ▸ Report a problem…**. Describe what you were trying to do,
   what you clicked, and what happened. Include the message if one appeared.
2. Review the attachments. You can include recent errors, information about
   your setup, and the last 200 activity log entries. The log includes
   filenames. Uncheck anything you'd like to leave out. The preview shows what
   will be sent.
3. Add an email address if you'd like a reply, then send the report. Keep the
   report number if you want to ask about it later.

Use **Help ▸ Send feedback…** for an idea or comment. Feedback starts with no
attachments selected. Reports go directly to the developer. [Privacy](../privacy.md).

## Version, updates and settings

- **Help ▸ What's new** shows changes in your release. It opens automatically
  after a browser update to drawbar. On the desktop it opens the release page.
- **Help ▸ About drawbar** shows the version, project links and licenses. On
  macOS, find **About drawbar** in the **drawbar** menu.
- **Help ▸ Share anonymous usage** turns browser usage counts on or off.
  The desktop app sends no counts. [See what drawbar collects](../privacy.md#anonymous-usage-and-error-counts).
- **Help ▸ User guide** opens this guide, and **Help ▸ Welcome** brings back
  the choices to connect, import files or start with demo sounds.
