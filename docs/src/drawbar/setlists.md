# Set lists and notes

A *song* in a set list remembers which programs you want to call up. A text
note keeps lyrics or cues in your library beside the sounds.

## Set lists

1. Double-click a song to see its program entries in playing order.
2. Drag a row to move it earlier or later in the song.
3. To choose a different program, enter its bank and slot as shown on the
   keyboard.

Changing the order of programs in a song leaves the programs themselves alone.

Check the **State** column before rehearsal. Connect the instrument to see
program names and check each entry.

| State | Means |
|---|---|
| **resolves** | The entry plays the program in that slot. |
| **not read yet** | drawbar hasn't read that bank, so what's there is unknown. |
| **no program at 1:2** | drawbar has read the bank, and the slot is empty. |

To carry a song *and* the sounds it plays to another computer, [export a bundle](bundles.md).

## Notes

Choose **New ▸ Text note** for lyrics, cues or a set list you just want to
read. Type, save and tag the note like any other library file. You can also
open plain text such as a `.txt` or `.md` file up to 256 KiB. Notes stay on the
computer.
