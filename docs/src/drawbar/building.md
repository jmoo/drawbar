# Build your own sounds

drawbar turns your own recordings into sounds the keyboard plays.

| You have | Build | Start here |
|---|---|---|
| One WAV per note, for a sound mapped across zones of the keyboard | A sample instrument | [Make a sample instrument](samples.md) |
| One WAV per recording of a note, with layers, pedal or release sounds | A piano library | [Build a piano](pianos.md#a-new-library) |
| One long WAV of notes played one after another | A piano library, from the take | [Make a piano from a recording](recording.md) |

A piano that is too large for the keyboard's free memory can be
[trimmed to fit](pianos.md#trim-to-fit).
