# Keyboard shortcuts

| To… | Mac | Windows and Linux |
|---|---|---|
| Search the library | <kbd>⌘K</kbd> | <kbd>Ctrl+K</kbd> |
| Import files | <kbd>⌘O</kbd> | <kbd>Ctrl+O</kbd> |
| Save | <kbd>⌘S</kbd> | <kbd>Ctrl+S</kbd> |
| Export | <kbd>⇧⌘E</kbd> | <kbd>Ctrl+Shift+E</kbd> |
| Undo | <kbd>⌘Z</kbd> | <kbd>Ctrl+Z</kbd> |
| Redo | <kbd>⇧⌘Z</kbd> | <kbd>Ctrl+Shift+Z</kbd> |
| Rename the selected file | <kbd>F2</kbd> | <kbd>F2</kbd> |
| Review the send queue | <kbd>⇧⌘S</kbd> | <kbd>Ctrl+Shift+S</kbd> |
| Read everything from the instrument | <kbd>⌘R</kbd> | <kbd>Ctrl+R</kbd> |
| Close the tab | <kbd>⌘W</kbd> | <kbd>Ctrl+W</kbd> |
| Show the Keyboard tab | <kbd>⌘2</kbd> | <kbd>Ctrl+2</kbd> |
| Show the last document you had open | <kbd>⌘3</kbd> | <kbd>Ctrl+3</kbd> |
| Hide or show the left panel | <kbd>⌥⌘B</kbd> | <kbd>Ctrl+Alt+B</kbd> |
| Hide or show the inspector | <kbd>⌥⌘I</kbd> | <kbd>Ctrl+Alt+I</kbd> |
| Open the activity log | <kbd>⌥⌘L</kbd> | <kbd>Ctrl+Alt+L</kbd> |
| Zoom in, out or reset | <kbd>⌘+</kbd> <kbd>⌘−</kbd> <kbd>⌘0</kbd> | <kbd>Ctrl++</kbd> <kbd>Ctrl+−</kbd> <kbd>Ctrl+0</kbd> |

A browser keeps some of these keys for itself. There, the tab keys
(<kbd>W</kbd>, <kbd>2</kbd> and <kbd>3</kbd>) take <kbd>⌃</kbd> on a Mac and
<kbd>Alt</kbd> elsewhere, and the zoom keys zoom the page.
[Keys for the panel controls](editing.md#work-with-the-panel-controls).
