# Organize your sounds

For a gig, you might keep the programs, a set list and a note with stage cues in
one folder. Tags let you find the same sounds again by band, venue or song,
wherever you filed them.

## Add files or start a folder

1. Drop your files on the window, or choose **File ▸ Import…**. drawbar copies
   supported files into **This computer**. You can keep using the originals.
2. Choose **New ▸ New folder** and give it a name, such as *Friday set*.
   Drag sounds from **This computer** into the folder.
3. Choose **New ▸ Text note** for cues. Type your note, choose **File ▸ Save**,
   and move it into the folder with the sounds.

Already have the files arranged in a folder? [Open the folder as your library](this-computer.md#opening-another-folder)
to work on them where they are. **New** also offers blank sounds by instrument
family. Some start with every control at zero.

## Select and tag sounds

Click a row to select it. Hold Command on a Mac or Ctrl on Windows or Linux to
add individual rows. Shift-click the last row of a range to select the whole
range. Right-click the selection to see what you can do with it.

Open **Tag** in the row menu or **Add tag** in the inspector. Pick an
existing tag, or choose **New tag…** and type a name. For example, give the sounds you use in the encore an *Encore*
tag. You can also tag a note or a WAV. In the inspector's **Tags** card, click a
tag to apply or remove it across the selection.

Rename a tag to an existing tag's name to merge the two. Removing a tag leaves
its sounds in place.

## Find a sound

Click the search box at the top (Command-K or Ctrl-K) and enter part of the
name. In **Library**, click a column heading to sort. Choose a kind or tag on
the left to narrow the list. Selecting two tags shows sounds that have both.
Click a selected filter again to remove it.

With a keyboard connected, **Where** shows whether a sound is on the computer,
the instrument, or both. An equals sign means the copies match. **≠** means
they differ. **Needs** names the sample or piano a program uses when drawbar
knows it. Select the sound to see its **Dependencies** in the inspector.
Use **Waiting to send** to find queued sounds.

## Rename, remove or undo

Select a file and press F2 to rename it. If the name is taken, **Keep both**
gives your file a free name. **Overwrite** replaces the existing file.
Removing a folder moves its contents up one level. If drawbar finds hidden
files, **Show them** lets you inspect them before you decide.

**Edit ▸ Undo** names the last library change you can take back. A move, save,
deletion or tag change affecting several files is one step. **Edit ▸ Redo**
repeats it. For an edit you haven't saved yet, choose **Revert** in the open
document. Undo lasts for this window's session with the library. Deleted and
overwritten files are kept for Undo up to 1 GiB, the oldest going first, and
quitting empties that trash.

## Export files for someone else

Choose **Export…** in an open document to save a separate copy. To export
several, select their rows on this computer and choose **File ▸ Export…**.
For a song or program that needs other sounds to play, [export a bundle](this-computer.md#bundles).
