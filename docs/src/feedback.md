# Send feedback

Tell drawbar's developer what would make drawbar better for you: an idea,
something that was hard to find in the app or in this guide, or a project that
belongs on the [Community](community.md) page.

<textarea id="feedback-text" name="text" rows="8" maxlength="5000" required></textarea>

</form>
<noscript>

This form needs JavaScript. You can write to
[contact@drawbar.app](mailto:contact@drawbar.app) instead.

</noscript>

The form sends what you write, your email address if you give one, and a note
that it came from the guide. It goes privately to the developer.
[What happens to a report](privacy.md#reports-you-send).

For a problem inside the app, use
[**Help ▸ Report a problem…**](drawbar/help.md#report-a-problem) instead. It can
attach the activity log and recent errors, which this page cannot. If you use
GitHub, you can also [open an issue](https://github.com/jmoo/drawbar/issues).
