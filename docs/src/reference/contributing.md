# Contributing

The contributor guide lives in the repository and is the authority on style,
testing, tooling and the release process:

- [CONTRIBUTING.md](https://github.com/jmoo/drawbar/blob/master/CONTRIBUTING.md)
- [Issues and pull requests](https://github.com/jmoo/drawbar/issues)

Two boundaries are worth repeating here.

**All reverse engineering is black-box work for interoperability.** Formats and
protocol behavior are derived from self-generated specimen files, captured USB
traffic, public documentation, and hardware observation on instruments the
researcher owns. Clavia software and firmware are not decompiled or
disassembled.

**Nothing proprietary is committed.** Factory presets, sample or piano
libraries, firmware, and files shipped with Clavia software stay out of the
repository; committed fixtures are self-generated by the project's own tools or
taken from the instrument panel.

## Building the docs

This site is an [mdBook](https://rust-lang.github.io/mdBook/). From the
repository root:

```sh
nix build .#docs                  # render the guide
nix develop -c mdbook serve docs  # preview it
```
