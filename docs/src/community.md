# Community

## Chris55

- [nord-documentation](https://github.com/Chris55/nord-documentation), rendered
  at [chris55.github.io/nord-documentation](https://chris55.github.io/nord-documentation/):
  byte maps for the Stage 2 and Stage 3 program files and the Lead A1, built by
  diffing saved files one control at a time. The first public decode of the
  Stage 2 and 3 formats, as far as we know, and the source of drawbar's Stage 2
  and 3 field placements.
- [ns3-program-viewer](https://github.com/Chris55/ns3-program-viewer): a
  read-only web viewer for Stage 2, 2EX and 3 programs, built on those maps.

## ns4decode

[ns4decode](https://ns4decode.netlify.app) by Randy (MIT): a Stage 4 file viewer
that publishes its offset tables. The first public decode of the Stage 4 program
and preset files, as far as we know, and the source of drawbar's Stage 4
placements.

## Adding to this list

If you maintain a project that works with Nord files or instruments, open a pull
request against this page.
