# Piano test file naming convention

```
abcd_ee_ff.ne5p

a = part select (0: lower, 1: upper)
b = acoustics (0: off, 1: string_res, 2: long release, 3: both) 
    string release only on grand and harp
    long release only on grand, upright, ep1, ep2
c = mono (on/off)
d = kbd touch (0: off, 1, 2, 3)
e = type (1: ep1, 2: ep2, 3: clav, 4: harps, 5: grand, 6: upright)
f = model
```
