# Settings file

### System settings
```
abcdefghiijjjkk.ne5p

a: memory protection (0: off, 1: on)
b: rotary ctrl type (0: closed, 1: open, 2: half-moon)
c: rotary pedal mode (0: hold, 1: toggle)
d: sustain pedal mode (0: sustain, 1: sustain +  rotor hold, 2: sustain + rotar toggle)
e: b3 trig mode (0: normal, 1: fast)
f: output routing mode (0: stereo, 1: partL:L/partU:R)
g: sustain pedal type (0: auto, 1: closed, 2: open)
h: ctrl pedal type (0: ev7, 1: fc7, 2: exp2, 3: xvp10, 4: fv500l, 5: fatar SL)
i: global transpose semitones (-6..6)
j: fine tune cent (-50..50)
k: ctrl pedal gain (1..10)
```

### Midi settings
```
abcdefgh.ne5p

a: local control (0: off, 1: on)
b: global channel (0: off, 1..16)
c: lower recieve channel (0: off, 1..16)
d: upper recieve channel (0: off, 1..16)
e: upper split channel (0: off, 1..16)
f: control change mode (0: off, 1: send, 2: recieve, 3: send/recieve)
g: program change mode (0: off, 1: send, 2: recieve, 3: send/recieve)
h: transpose midi at (0: in, 1: out)
```

### Sound settings
```
aabcdefghijklmno.ne5p
a: piano string res level (-6..6)db
b: b3 tonewheel mode (0: clean, 1: vintage1, 2: vintage2, 3: vintage3)
c: b3 keyclick level (0: low, 1: normal, 2: high, 3: higher)
d: b3 keybounce mode (0: off, 1: on)
e: b3 perc db9 mute mode (0: off, 1: on)
f: b3 perc decay fast (0: short, 1: medium, 2: long)
g: b3 perc decay slow (0: short, 1: medium, 2: long)
h: b3 perc volume normal (0: low, 1: medium, 2: high)
i: b3 perc volume soft (0: low, 1: medium, 2: high)
j: rotary speaker type (0: 122, 1: 122close) (weird dialing here seems like duplicate options so mapping may be weird)
k: rotary balance bass/horn (0: 70/30, 1: 60/40, 2: 50/50, 3: 40/60, 4: 30/70)
l: rotary horn speed (0: low, 1: normal, 2: high)
m: rotary horn acc (0: low, 1: normal, 2: high)
n: rotary rotor speed (0: low, 1: normal, 2: high)
o: rotary rotor acc (0: low, 1: normal, 2: high)
```
